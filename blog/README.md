# Building a Facebook Marketplace listing helper

A series on building Marketplace Listing Helper, a small Chrome extension that keeps a
list of things I'm selling, pairs photos with each item, and pre-fills Facebook
Marketplace's Create listing form. It never presses Next or Publish: I review every
listing and publish it myself. Each post covers one real step in building it, in order.

1. [A helper that never presses Publish](01-a-helper-that-never-presses-publish.md)
2. [Filling in Facebook's form](02-filling-in-facebooks-form.md)
3. [A list that lives in the browser](03-a-list-that-lives-in-the-browser.md)
4. [From a spreadsheet to listings](04-from-a-spreadsheet-to-listings.md)
5. [A full-page manager, without a bundler](05-a-full-page-manager-without-a-bundler.md)
6. [Photos that don't lag or vanish](06-photos-that-dont-lag-or-vanish.md)
7. [Linking listings that already exist](07-linking-listings-that-already-exist.md)

Each post ends with a hidden HTML comment listing the commits it covers; blog-sync strips
those before posting. The project wasn't under version control when these were written, so
they say so instead of listing commits.
